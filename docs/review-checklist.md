# Review Checklist

## Antes de finalizar
- [ ] O escopo pedido foi atendido sem refatoracao paralela desnecessaria.
- [ ] Layout principal continua coerente.
- [ ] Responsividade foi checada em desktop e mobile quando a UI mudou.
- [ ] Rotas, slugs, ids e classes sensiveis continuam validos.
- [ ] Build foi executado quando aplicavel.
- [ ] Lint foi executado quando aplicavel.
- [ ] Typecheck foi executado ou o motivo foi informado.
- [ ] Testes foram executados ou a ausencia de suite foi informada.
- [ ] Performance de scroll/video/motion foi considerada.
- [ ] Acessibilidade basica foi revisada: foco, labels, contraste e reduced motion.
- [ ] Nenhum segredo, token ou dado sensivel foi adicionado.
- [ ] Arquivos criados e alterados foram listados.
- [ ] Riscos, verificacoes faltantes e proximos passos foram anotados.
