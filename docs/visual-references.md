# Visual References

Use estas referencias como inspiracao, nao como fonte para copiar codigo, assets ou composicao literal.

## Referencias
- https://ribbit.dk/
- https://panamaera.fr/print
- https://lusion.co/
- https://taotajima.jp/

## O que observar
- Visual premium e hierarquia com pouco ruido.
- Animacoes fluidas com resposta clara ao gesto.
- Scroll criativo que continua legivel e controlavel.
- Microinteracoes que reforcam navegacao.
- Uso de WebGL/Three.js quando o efeito precisa de geometria, textura ou distorcao.
- Transicoes elegantes entre estados, rotas e cards.

## Como aplicar no projeto
- Adapte comportamento e principios ao catalogo floral atual.
- Preserve performance, acessibilidade basica e leitura dos titulos.
- Documente a diferenca entre referencia visual e implementacao local.
- Evite copiar codigo proprietario, shaders, assets ou timing sem entendimento.
